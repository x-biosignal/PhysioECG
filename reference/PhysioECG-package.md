# PhysioECG: ECG Analysis Functions for PhysioExperiment Objects

Provides electrocardiography (ECG) analysis functions for
PhysioExperiment objects. Includes R-peak detection (adaptive
Pan-Tompkins), RR interval computation, HRV time-domain metrics (SDNN,
RMSSD, pNN50), HRV frequency-domain analysis (VLF, LF, HF power),
nonlinear HRV (Poincare, Sample Entropy, DFA), ECG morphology analysis
(QRS boundaries, QT/QTc intervals), and signal quality assessment with
ectopic beat correction.
