# Compute DFA slope for a given scale range

Compute DFA slope for a given scale range

## Usage

``` r
.dfa_slope(log_scales, log_fluct, scales, range)
```

## Arguments

- log_scales:

  Log of scale values.

- log_fluct:

  Log of fluctuation values.

- scales:

  Original scale values.

- range:

  Numeric vector of length 2 (min_scale, max_scale).

## Value

Numeric slope (alpha exponent).
