# Integrate PSD within a frequency band

Integrate PSD within a frequency band

## Usage

``` r
.band_power(freqs, psd, band)
```

## Arguments

- freqs:

  Frequency vector.

- psd:

  PSD vector.

- band:

  Numeric vector of length 2 (low, high) in Hz.

## Value

Numeric scalar: integrated power in the band.
